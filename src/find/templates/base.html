Find

Wellcome to Find, a small search application for all gioorgi.com sites.
Some Tips:
  • Use FTS queries like sqlite OR postgres, title:git, use double quote to search exact phrases like "title git"
  • Google-like site:8bit.gioorgi.com syntax is supported, for instance to search only on companion sites
Note: a rate limiter is active by default.
